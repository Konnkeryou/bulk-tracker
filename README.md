# Bulk Tracker

Offline-first PWA for a home-gym bulk: weigh-ins with a 7-day trend, workouts with estimated 1RM, a plate calculator for the plates you own, meals, waist, progress-photo dates, and a review screen for success metrics.

- All data stays on the device (IndexedDB). Export JSON/CSV from **More**.
- No build step: plain ES modules. Serve the folder over HTTPS (or localhost).
- Tests for the maths: `npm test` (Node 20+).

Install on iPhone: open in Safari → Share → **Add to Home Screen**.
